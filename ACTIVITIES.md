**1. Explain the concept of object-oriented programming in simple terms to a complete beginner.**
Aspect Tested: 
Sure! Imagine you want to organize your stuff at home. Instead of just having a big messy pile, you put things into boxes. Each box holds similar things—like one box for toys, another for books, and another for clothes.

Object-oriented programming (OOP) is kind of like that, but for organizing code when you write programs.

Here’s the simple idea:

1. **Objects Are Like Boxes:** In OOP, you create "objects." Each object is like a box that holds both information (called **data**) and actions it can do (called **methods** or **functions**).

2. **Classes Are Like Blueprints:** Before making objects (boxes), you need a blueprint or template that describes what the object will have and what it can do. This blueprint is called a **class**.

3. **Example:** Imagine you want to create a program about dogs.
   - You make a **class** called `Dog`.  
   - This class says every dog has a name, an age, and can do things like bark or wag its tail.
   - Each actual dog you create (like your pet dog "Max") is an **object** created from the `Dog` class.

4. **Why is OOP useful?**  
   - It keeps your code organized.  
   - You can reuse code easily by creating many objects from the same class.  
   - It models real-world things more naturally because in real life, things have properties and can do things.

In short, object-oriented programming is a way to write and organize code by creating objects that represent things with their own data and actions.

- Apples come in packs of 4.
- Oranges come in packs of 3.

Let:
- \( x \) = number of apple packs
- \( y \) = number of orange packs

We need:
\[
4x = 12 \implies x = \frac{12}{4} = 3

\[
